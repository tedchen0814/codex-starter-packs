# 開工接續

- 先依對話確認專案位置，讀取該專案的工作筆記（`工作筆記.md`），僅摘要最近進度、下一步與相關問題。
- 有 Git repo 時檢查本機狀態；已有 origin 時可 fetch 後判斷遠端差異。無 Git 的筆記、研究或簡報專案仍可恢復工作脈絡，不要求建立 repo。
- 「開工」本身只授權讀取與檢查：不改檔、不 pull/rebase/checkout/reset。若同一句或既有對話已授權具體工作，檢查後直接接續該工作。
- 只有開工而沒有指定工作時，報告狀態並提供一至兩個下一步，等待選擇。
- 遠端或工具無法使用時回報可確認的狀態，不自行登入、建立遠端或變更設定。
- 找不到工作筆記時，回報「這個專案還沒有工作筆記」，不要自行建立。
