# 專案初始化

## 先確認（缺的才問，已提供的不要重問）

1. 專案名稱與用途（一句話）。
2. 建立在哪個資料夾；先檢查是否已有同名或近似名稱的資料夾，**不要覆蓋既有內容**，有就停下來問。
3. 是否要建立 GitHub repo？預設**不建**；要的話一律建立為**私有**，且先說明再等同意。
4. 使用者有 Obsidian 筆記庫（已完成 `codex-obsidian`）時，是否要在筆記庫登錄這個專案。

## 建立內容

- 專案資料夾。
- `README.md`：名稱與一句話用途。
- `AGENTS.md`：專案規則（使用繁體中文、不提交憑證與個人資料、修改前說明）。
- `工作筆記.md`：名稱、狀態「進行中」、上次做到哪、下一步（讓 `startup-sync`、`shutdown-sync` 讀寫）。
- `.gitignore`：至少排除 `.env`、`.codex/`、`.claude/`、`*.key`、`node_modules/`。
- `git init`（只在本機；建立遠端 repo 或 push 需使用者同意）。

## 驗證與回報

回讀每個檔案確認中文顯示正常，列出：檔案清單、Git 狀態，以及（若有建立）GitHub 網址與 Obsidian 筆記路徑。

## 安全界線

- 初始化不包含公開、部署或新增外部服務。
- 筆記與檔案中不存放 token、API key、密碼。
- 工具不可用（例如 Obsidian 未連線）時，明確回報，不要宣稱已登錄。
